# Şəhər və marka kataloqu

Siyahılar `src/catalog.js` faylındadır: 134 avtomobil/light-commercial marka seçimi ("Digər" daxil olmaqla) və 79 şəhər/rayon mərkəzi. Bunlar mövcud elan sayı və ya avtomobilin kirayəyə hazır olduğunun göstəricisi deyil.

14 noyabr 2026 tarixində [Turbo.az](https://turbo.az) açıq axtarış formasındakı marka və məkan adları ümumi məlumat arayışı kimi yoxlanılıb. Öz siyahımızda əvvəlki marka adları qorunub, avtomobil və yüngül kommersiya istehsalçıları əlavə olunub; motosiklet və ağır texnika markaları avtomatik köçürülməyib. Məkan siyahısı Kəlbəcər, Zəngilan, Qıvraq və Heydərabadla tamamlanıb. Loqo, foto, elan və təsvir mətnləri götürülməyib. Siyahı bütün yaşayış məntəqələrinin rəsmi reyestri deyil.

`CatalogSelect` kataloqda və elan formasında eyni saxlanan dəyərlərdən istifadə edir. Ekrandakı tərcümə dəyəri dəyişdirmir: məsələn, "Баку" seçimi `Bakı` kimi saxlanır. Yazı axtarışı Azərbaycan hərflərini və sadə Latın girişini uyğunlaşdırır; `seki`, `ismayilli`, `skoda`, `mersedes` ilə seçim tapmaq mümkündür. Əvvəlki elanlarda olan siyahıdan kənar dəyər redaktə zamanı saxlanır.

Şrift: yerli Onest Variable (400–450 çəkiləri). Şrift lisenziyası `public/licenses/Onest-OFL.txt` faylındadır. Xarici font sorğusu tələb olunmur.
